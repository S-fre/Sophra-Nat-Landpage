## Description - Français

Sophra'Nat est un site vitrine pour Catherine Allart, praticienne en naturopathie, massage bien-être et réflexologie à Bonneville.

Le site présente :
- les accompagnements proposés ;
- les informations de contact ;
- les horaires du cabinet ;
- les avis clients ;
- les liens de prise de rendez-vous ;
- les pages légales : mentions légales, confidentialité et cookies.

La naturopathie n'est pas un dispositif médical et ne remplace pas un avis médical pour certaines pathologies.

## Description - English

Sophra'Nat is a showcase website for Catherine Allart, a practitioner offering naturopathy, wellness massage and reflexology in Bonneville, France.

The website includes:
- the services offered ;
- contact information ;
- office opening hours ;
- client reviews ;
- appointment booking links ;
- legal pages: legal notice, privacy policy and cookies.

Naturopathy is not a medical device or treatment and does not replace medical advice for specific health conditions.

## Télécharger le site

Pour télécharger une copie du site depuis GitHub :

1. Cliquer sur le bouton vert `Code`.
2. Cliquer sur `Download ZIP`.
3. Décompresser le fichier ZIP téléchargé.
4. Ouvrir le fichier `index.html` dans un navigateur.

Important : le dossier `ressources` doit rester au même endroit que `index.html`, car il contient les images, la vidéo, la musique et le logo du site.
